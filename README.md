
# QuizMaster – Team 6 Impact Makers

## About
QuizMaster is an interactive quiz application developed by Team 6 – Impact Makers.

## Features
- Multiple-choice questions
- Instant answer feedback
- Score calculation
- Progress indicator
- Restart quiz option
- Responsive interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Git and GitHub

## How to Run
1. Clone this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start answering questions.
